# 12-1 CAN 总线环回测试

## 功能

- 按键 1 发送一帧标准数据帧：`ID=0x123`、`DLC=2`、数据 `0x66 0x88`
- CAN 工作在**环回模式**，自己发、自己收，不需要外部节点
- OLED 显示收到的 `RxID / Leng / Data`

## 硬件

| 信号 | 引脚 |
|---|---|
| CAN_RX | PA11 |
| CAN_TX | PA12 |

- 环回测试**不需要收发器**；
- 接真实总线时加 TJA1050（5V）或 SN65HVD230（3.3V），总线两端各 120Ω。

## 当前配置

- 模式：`CAN_Mode_LoopBack`
- 位时序：`Prescaler=48`、`BS1=2tq`、`BS2=3tq`
  - PCLK1=36 MHz 时：`tq=1.333µs`，`N=6`，位时间 `8µs` → **125 kbps**
  - 采样点 `(1+2)/6 = 50%`
- 过滤器：全收（ID=0，Mask=0）

> 50% 采样点只适合环回自测。接真实总线建议改成 500 kbps：
> `Prescaler=4`、`BS1=15tq`、`BS2=2tq`、`SJW=1tq`（采样点 88.9%）。

## 测试现象

1. 编译下载；
2. OLED 显示 `RxID:`、`Leng:`、`Data:`；
3. 按按键 1，应显示 `123`、`02`、`66 88`。

## 文件

- `hardware/MyCAN.c/h`：CAN 初始化、发送、接收
- `main.c`：按键发送 + OLED 显示

## 备注

- 环回模式不经过收发器和线缆，只能验证 bxCAN 内部通路；
- 切到 `CAN_Mode_Normal` 上真实总线时，必须加收发器、终端电阻和共地。

# 12-3 标准格式 / 扩展格式 / 数据帧 / 遥控帧

## 功能

按键 1 依次发送 4 种帧，环回模式下自己收自己，OLED 显示接收结果：

| 顺序 | 帧类型 | ID | DLC | 数据 |
|---|---|---|---|---|
| 1 | 标准数据帧 | 0x555 | 4 | 11 22 33 44 |
| 2 | 扩展数据帧 | 0x12345678 | 4 | AA BB CC DD |
| 3 | 标准遥控帧 | 0x666 | 0 | 无 |
| 4 | 扩展遥控帧 | 0x0789ABCD | 0 | 无 |

## 现象

- 标准帧显示 `Std`，扩展帧显示 `Ext`；
- 数据帧显示 `Data` 和 4 字节数据；
- 遥控帧显示 `Remote`，数据字节显示 00。

## 说明

- 模式：`CAN_Mode_LoopBack`；
- 过滤器：全收；
- 位时序：`Prescaler=48, BS1=2tq, BS2=3tq`（36 MHz 下 125 kbps）。

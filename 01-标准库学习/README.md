# 01-标准库学习

配合江协科技《STM32 入门教程》学习，STM32F103 + 标准库（SPL）。每个文件夹是一个完整的 Keil 工程。

## 目录索引（学习进度）

| 文件夹 | 模块 | 学到的知识点 |
|---|---|---|
| 2-1stm32project | 新建工程 | 工程结构、启动文件、时钟 |
| 3-2LED流水灯 | LED | GPIO 输出、位操作 |
| 3-3蜂鸣器 | 蜂鸣器 | GPIO 驱动外设 |
| 3-4按键控制LED | 按键 | GPIO 上拉输入、消抖 |
| 3-5光敏传感器控制蜂鸣器 | 光敏 | ADC 输入（模数初步） |
| 4-1OLED的使用 | OLED | I2C/SPI 协议、模块驱动 |
| 5-1对射式红外传感器计次 | 红外计次 | 外部中断 EXTI |
| 5-2旋转编码器计次 | 编码器 | EXTI 双边沿、编码原理 |

| 6-2定时器外部时钟 | 定时器 | 外部时钟模式 |

## 每个模块的"三改"要求

学完每个外设，在教程代码基础上至少做三处自己的改动：

1. **改参数**：换引脚、换频率、换触发方式
2. **加功能**：加一个 LED 反馈 / 串口打印寄存器值
3. **写原理**：在 README 里写一段自己的理解（时钟树、寄存器、踩坑）

改过的代码才是"你的代码"。

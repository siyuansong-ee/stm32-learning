# STM32 底层内核系列（Cortex-M3）学习笔记

> 定位：你已经跑通了标准库的全部外设（GPIO/EXTI/TIM/PWM/输入捕获/编码器/ADC/DMA/USART/I2C/SPI），
> 这一系列笔记不教外设，**只教"外设背后的内核"**：你的每一行 `NVIC_Init`、每一个 `IRQHandler`、
> 每一次上电复位，在内核（Cortex-M3）和总线层面到底发生了什么。
> 所有讲解都从 **你仓库里的真实代码** 出发（给出文件与行号），并标注手册章节。

## 建议的学习方法

1. **每篇都跟着代码读**：文中引用的文件就在本仓库 `01-标准库学习/` 下，用 Keil 打开对应工程，边读文档边在源码里跳转。
2. **手上开三个窗口**：代码 + 本笔记 + PDF 手册，遇到寄存器定义就 `Go To Definition` 到 `core_cm3.h` / `stm32f10x.h`。
3. **寄存器层面亲手算一遍**：例如 Group2 分组下 `pre=2, sub=1` 写入 IPR 的值是不是 `0x90`，算不出来就看 03 篇。
4. **改一个例子**：把 04 篇的 HardFault 现场打印代码粘进你的 `stm32f10x_it.c`，故意写一个越界数组，亲手抓到一次 HardFault——做过一次，胜过读十遍。

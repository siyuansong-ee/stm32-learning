# 08 · 面试题库：内核篇（面试官视角）

> 本篇是 01–07 的"输出验收"。每道题给三层：**面试官在考什么 → 及格答案 → 加分答案**。
> 及格答案靠背，加分答案靠前面几篇的理解。题目难度 ★ 递增，覆盖校招到社招。

## A. 启动与链接（对应 01 篇）

**A1. 从按下复位键到 main() 执行，中间发生了什么？** ★★
- 考点：是否理解"程序不是凭空跑的"。
- 及格：复位后 CPU 从地址 0 取 SP、地址 4 取 PC → Reset_Handler → SystemInit 配时钟 → 进 main。
- 加分：补齐细节——boot 引脚决定 0x0 的别名指向（RM0008 §2.4）；`__main`（非 main）先做 RW 段搬运、ZI 段清零（scatterload），再调 main；SystemInit 里"先 Flash 等待周期、后切 PLL、再 VTOR"的顺序与原因。

**A2. 为什么向量表第一项是栈顶地址？** ★★
- 考点：复位时序 + 栈的本质。
- 及格：复位后 CPU 要立刻用栈，没人用汇编给 SP 赋值，硬件规定从 0x0 读 SP。
- 加分：能说出第二项是 Reset_Handler 的 PC；每项 4 字节；F103 表共 59 项 236 字节；VTOR 对齐要求 512 字节（IAP 时 0x2000 起跳的由来）。

**A3. `__main` 和 `main` 有什么区别？ZI 段和 RW 段分别放哪、谁初始化？** ★★★
- 及格：`__main` 是 C 运行库入口，main 是用户入口；RW 初值在 Flash，ZI 在 RAM 里清 0。
- 加分：全局未初始化变量=ZI（你的 `uint16_t Num`）、已初始化= RW（`int x=5`）、局部 static 同全局；const 在 RO 段；"全局变量初值莫名丢失"先查 scatterload/链接配置。

**A4. 启动文件里 `[WEAK]` 是什么？中断函数名写错会怎样？** ★★★
- 考点：链接器符号规则（几乎必考）。
- 及格：弱符号，被强符号覆盖；写错名字就用默认死循环版本。
- 加分：默认版本就是 `B .`（原地跳转），所以现象是"程序卡死、PC 停在死循环"；这也是为什么 it.c 里重写 HardFault_Handler 不用改 .s。

**A5. Boot0/Boot1 怎么影响启动？系统存储器 0x1FFFF000 是什么？** ★★★
- 及格：三选一启动介质（Flash/系统存储器/SRAM），通过别名映射到 0x0。
- 加分：系统存储器=出厂 BootLoader，串口 ISP 烧录的原理；选项字节（读保护）在 0x1FFFF800；Flash 被锁死后靠 BOOT1=0/BOOT0=1 进 BootLoader 救砖。

## B. 内核架构（对应 02 篇）

**B1. Cortex-M3 和 Cortex-M4 差什么？F103 的内核有什么、没什么？** ★★
- 及格：M4 多了 FPU/DSP 指令（可选 MPU）。
- 加分：F103 = M3 r1p1：无 FPU/MPU/Cache，有 NVIC/SysTick/位带/Thumb-2；CPUID 0x411FC231 的含义；顺带能说"浮点运算在 F1 上是软件模拟，中断里别做浮点"。

**B2. 寄存器 R0–R15 各自角色？LR 和 PC 的特殊性？** ★★★
- 及格：R13=SP、R14=LR、R15=PC，R0-R3 传参。
- 加分：进异常后 LR 被硬件改成 EXC_RETURN（0xFFFFFFF9 等）；PC 的 bit0 是 T 位（所以函数指针是奇数）；M3 有 MSP/PSP 两个物理 SP。

**B3. AAPCS 调用约定：哪些寄存器调用者保存、哪些被调用者保存？** ★★★
- 及格：R0-R3/R12/LR 调用者保存，R4-R11 被调用者保存。
- 加分：`PUSH {R4,LR}`/`POP {R4,PC}` 这对称呼的语义；SP 8 字节对齐（启动文件 PRESERVE8）；64 位返回值 R0:R1。

**B4. Thread/Handler 模式、特权/非特权、MSP/PSP 的关系？** ★★★★
- 及格：裸机=Thread+特权+MSP；中断里=Handler。
- 加分：2×2 组合表；CONTROL 寄存器 bit0/bit1；非特权化的意义（隔离）；Handler 模式强制 MSP；PSP 是为 RTOS 任务栈设计的。

**B5. 进入异常时硬件自动做了什么？** ★★★★
- 及格：压栈（8 个寄存器）、取向量、更新 LR/IPSR。
- 加分：压栈顺序 xPSR/PC/LR/R12/R3-R0（低地址起 R0…）；这是纯硬件行为所以 ISR 是普通 C 函数；出栈由 EXC_RETURN 触发；能提 tail-chaining/late-arriving 直接进下一题。

## C. NVIC 与中断（对应 03 篇）

**C1. 中断从外设事件到 ISR 执行经过哪几级开关？** ★★★★
- 及格：外设中断使能（DIER）→ NVIC 使能（ISER）→ CPU。
- 加分：三级串联图；每一级不开的现象（标志置位但不上报/上报但不响应）；NVIC 响应时自动清挂起位 vs 外设 SR 标志要软件清的区别——TIM 写 ClearITPendingBit、USART 读 DR 自动清、EXTI 写 PR。

**C2. 抢占优先级和子优先级区别？分组怎么配？** ★★★★
- 及格：抢占能嵌套打断，子优先级只排先后；`NVIC_PriorityGroupConfig` 全局唯一。
- 加分：F1 只有 4 位（16 级）；PRIGROUP 在 AIRCR；手算 Group2 下 pre=2/sub=1 → IPR=0x90；AIRCR 写保护 VECTKEY=0x05FA。

**C3. 两个中断同时挂起，谁先执行？中断响应延迟多少？** ★★★★
- 及格：先比抢占级，再比子优先级，最后比异常编号（小者先）。
- 加分：M3 名义 12 周期（零等待），尾链约 6 周期；F1 上还有 Flash 2 等待周期与总线竞争；ISR 要短的四个理由。

**C4. ISER 为什么"写 1 置位、写 0 无效"？** ★★★★
- 考点：读改写竞态与硬件设计思想。
- 及格：避免读-改-写。
- 加分：串到 GPIO 的 BSRR/BRR 同款设计（07 篇）；对比 `ODR |=` 的三步竞态；这也是"为什么标准库不用位带而用 BSRR"的引子。

**C5. EXTI5–9 共用一个 IRQ，ISR 里怎么分流？** ★★★
- 及格：`EXTI_GetITStatus` 逐线判断。
- 加分：你的 `EXTI15_10_IRQHandler` 案例；AFIO_EXTICR 选端口、AFIO 时钟只在 EXTI/重映射时开（你笔记里改过的那个点）；忘了清 PR 位会无限重入。

## D. 异常与 HardFault（对应 04 篇）

**D1. 程序跑飞进 HardFault，你怎么排查？** ★★★★★（社招必考）
- 及格：读状态寄存器定位原因 → 从栈取 PC → 反汇编定位。
- 加分完整流程：CFSR（MMFSR/BFSR/UFSR）+HFSR 判类型 → LR bit2 判 MSP/PSP → 栈偏移 +24 取 PC、+20 取 LR → Keil 反汇编 Go To Address → BFAR/MMFAR 查坏地址 → 分类根因（越界/野指针/时钟/栈溢出/IAP 向量表）。能报出 HFSR.FORCED 与 VECTTBL 位直接封神。

**D2. HardFault 和 BusFault/UsageFault 什么关系？** ★★★★
- 及格：可配置故障默认关闭，统一升级为 HardFault。
- 加分：SHCSR 三个 ENA 位打开后各回各家；F1 无 MPU 所以 MemManage 基本空转；UNDEFINSTR/INVSTATE/PRECISERR/IMPRECISERR 各对应什么代码；IMPRECISE 是因为写缓冲延迟报错。

**D3. 栈溢出有什么现象？怎么查？** ★★★★
- 及格：随机 HardFault/重启。
- 加分：你的栈才 1KB（启动文件 0x400）；溢出踩的是栈顶上的全局/中断现场，所以 PC 每次不同；查法：大数组 static 化、map 文件、观察 MSP 与 RAM 顶距离、canary 哨兵值。

## E. 时钟与 SysTick（对应 05 篇）

**E1. 画出 F103 时钟树，标出 72/36/72/12/9 各是什么。** ★★★★
- 加分：TIM2 在 APB1 上却 72MHz 的原因（APB1 分频≠1 时定时器 ×2）；ADC 12MHz（÷6，**SystemInit 没配，必须自己 RCC_ADCCLKConfig**）；SysTick 9MHz=HCLK/8；USART1 BRR=72e6/(16×9600)=468.75。

**E2. 为什么切 PLL 之前要先配 Flash 等待周期？** ★★★
- 及格：高频下 Flash 读要等待周期，先配好再提速。
- 加分：2WS@72MHz/1WS@24–48/0WS@≤24；预取缓冲 PRFTBE 把顺序执行的等待摊薄；降频时要反序操作；调错顺序=偶发取指错误。

**E3. SysTick 是几位的？你的 delay_ms(3000) 会怎样？** ★★★
- 及格：24 位，LOAD 最大 0xFFFFFF；9MHz 下单次最长 1.86s。
- 加分：3000×9000 溢出被截断 → 延时错误；RTOS 下 SysTick 归调度器，裸机 delay 要换 DWT CYCCNT；COUNTFLAG 读即清。

**E4. 为什么 PSC 写 7200-1？** ★★
- 及格：寄存器存 PSC+1。
- 加分：TIM 全系列"-1 魔咒"（PSC/ARR/CCR）；1Hz 推导：72M/7200/10000。

## F. RTOS 与底层并发（对应 06/07 篇）

**F1. PendSV 是什么？为什么任务切换用它？** ★★★★
- 及格：可挂起的系统调用异常，RTOS 用它切上下文。
- 加分：优先级压最低 → 等所有 ISR 跑完再切，不切走半个中断现场；ICSR.PENDSVSET 挂号；硬件压 R0-R3/R12/LR/PC/xPSR、软件压 R4-R11（AAPCS 分工）；EXC_RETURN=0xFFFFFFFD 返回 Thread+PSP。

**F2. SVC 和 PendSV 在 RTOS 里分工？** ★★★★
- 加分：SVC 特权操作"建局"（首个任务的 PSP/CONTROL），PendSV 低优先级"换局"；非特权任务代码改不了 CONTROL，必须借 SVC。

**F3. volatile 是什么？什么场景必须用？** ★★★★
- 及格：每次访问都真实读写内存；中断共享变量、寄存器、DMA 缓冲。
- 加分：不加 volatile 时 `while(flag==0);` 被优化成读一次的汇编；你的 `Serial_RxFlag` 正例、`AD_Value` 反例；volatile≠原子、≠屏障；const volatile=状态寄存器（__I）。

**F4. 单核单片机还有竞态吗？举例并给出解法。** ★★★★★
- 及格：有，中断打断产生的中间态。
- 加分：你的 `Serial_GetRxFlag` 读-清之间被打断 → 丢唤醒；解法：关中断包裹（`__disable_irq`/BASEPRI）、LDREX/STREX、位带原子写；临界区要短、要成对。

**F5. 位带是什么？换算公式？** ★★★★
- 及格：把位映射成 32 位地址，原子改位。
- 加分：公式默写；别名区必须字访问；PAout 宏展开；与 BSRR 方案的取舍。

**F6. 函数指针为什么是奇数？跳一个偶数地址会怎样？** ★★★
- 加分：bit0=T 位；偶数地址=Thumb 位 0 → INVSTATE UsageFault；野函数指针是 HardFault 头号来源之一。

## G. 开放题（考工程素养）

**G1. 你做过的最难调的 bug 是什么？** —— 期望答案包含：复现方法、逐层假设验证（外设→寄存器→总线→内核）、用到了什么工具（Keil 逻辑分析仪/寄存器窗口/反汇编/串口打印）。
**G2. 从 0 设计一个 BootLoader 要做哪些事？** —— Flash 分区、VTOR 重定位、跳转前关中断清状态、栈初始化（读新向量表第 0 项）、双区回滚、升级协议校验（CRC）、PM0075 的 Flash 擦写规则。
**G3. 72MHz 的 CPU 控制舵机（20ms 周期）你会怎么实现？** —— 评估定时器/中断/主循环方案取舍，考察是否理解"中断频率与任务时长"的权衡（呼应 C3）。
**G4. 给你一块没资料的板子，怎么点亮 LED？** —— 找晶振/看丝印/测电源，考察工程直觉与手册检索能力。

## 面试前 30 分钟速览清单

1. 复位时序三步：取 SP/PC → Reset_Handler → SystemInit → __main（RW 搬 ZI 清）→ main。
2. 异常压栈 8 字顺序，EXC_RETURN 三值，SP+24 取跑飞 PC。
3. NVIC 三级开关 + ISER"写 1 置位" + Group2 手算 0x90。
4. 时钟五兄弟：72(SYSCLK/HCLK/PCLK2/TIMx) / 36(PCLK1) / 12(ADC) / 9(SysTick)。
5. 位带公式、BSRR vs ODR、volatile 三场景。
6. PendSV 低优先级之谜：硬件压一半、软件压一半。

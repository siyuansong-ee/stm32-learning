# STM32 外设底层系列（寄存器级）笔记

> 上一套 [底层内核系列](../底层内核系列/README.md) 讲的是"外设背后的 CPU"（Cortex-M3）。
> 这一套讲的是**外设本身**：你写的每一行 `GPIO_Init` / `TIM_OC1Init` / `ADC_RegularChannelConfig`，
> 落到芯片里改动了哪些寄存器位、驱动了哪条硬件信号通路、产生了哪些标志位与事件。
> 每一个知识点都从你仓库 `01-标准库学习/` 里的真实工程代码出发（标注文件与行号）。

## 建议读法

1. 每篇开头有"你的代码长这样"小节，**先在 Keil 里打开对应工程**再往下读；
2. 每篇都有"寄存器电路图"（文字版）：画出寄存器、信号通路、标志位的连接关系——面试白板题就是画这些；
3. 每篇末尾的"工程体检"列出你代码里的**真实 bug 与隐患**（例如 5-2 编码器方向不计数、6-5 电机不反转、6-6 频率少个 0）——先去复现，再看分析；
4. 配合 [内核系列 03/04 篇](../底层内核系列/03-NVIC-中断机制与优先级.md) 读中断相关章节，外设中断源→NVIC 的完整链路在两套笔记里拼起来。

## 与内核系列的关系

内核系列回答"CPU 怎么响应中断/怎么跑指令"，本系列回答"外设怎么产生中断/寄存器怎么工作"。
两条线在 **NVIC（内核侧）与 外设中断标志（芯片侧）** 处交汇——这是面试官最爱考的边界。

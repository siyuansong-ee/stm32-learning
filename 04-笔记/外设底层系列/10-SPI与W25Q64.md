# 10 · SPI 与 W25Q64

> 你的代码：`11-1软件SPI读写W25Q64\hardware\MySPI.c`（GPIO 模拟模式 0）、
> `11-2硬件SPI读取W25Q64\hardware\MySPI.c` + `W25Q64.c`（硬件 SPI + 指令集）。
> 手册：RM0008 §21（SPI）、§21.3（功能描述）；W25Q64 Datasheet（指令表/状态寄存器/存储结构）。

## 10.1 你的代码长这样

```c
// 11-2 MySPI.c：SPI1，PA4=NSS(软件) PA5=SCK PA6=MISO PA7=MOSI
GPIO PA5/PA7 = AF_PP;  PA6 = IPU;  PA4 = Out_PP;     // 注意：PA6 上拉输入收数据
SPI_InitStructure.SPI_BaudRatePrescaler = SPI_BaudRatePrescaler_128;  // 72M/128 = 562.5kHz
SPI_InitStructure.SPI_CPOL = SPI_CPOL_Low;   SPI_CPHA = SPI_CPHA_1Edge; // 模式 0
SPI_InitStructure.SPI_Direction = SPI_Direction_2Lines_FullDuplex;
SPI_InitStructure.SPI_NSS = SPI_NSS_Soft;                  // NSS 用 PA4 手动拉
uint8_t MySPI_SwapByte(uint8_t ByteSend)
{ while(TXE==0);  SPI_SendData(ByteSend);
  while(RXNE==0); return SPI_ReceiveData(); }              // ★ 收发同时完成
```

## 10.2 SPI 的物理层：一个"环形移位"结构

SPI 主机/从机的移位寄存器**头尾相接成环**（RM0008 §21.3.1 框图）：

```
主机: [移位寄存器]MOSI ──► 从机: [移位寄存器]
      ▲            │MISO ◄──        │
      └────────────┘                └─►
每来一个 SCK 时钟：主机移出 1 bit，同时从机移入 1 bit（反向同理）
8 个时钟后：两边的寄存器整体交换 —— 所以"读一个字节"必须同时"发一个字节"
```

这就是 `MySPI_SwapByte` 名字的含义：**SPI 没有纯读也没有纯写，只有交换**。读 W25Q64 时发 `0xFF`（DUMMY）当"空转燃料"——你 W25Q64.c L84 正是这么干的。**"SPI 读数据为什么要发 Dummy 字节"**是必考面试题，答案就是移位环。

## 10.3 CPOL/CPHA：四种模式的时序（RM0008 §21.3.1 图，白板必画）

| 模式 | CPOL（空闲电平） | CPHA（采样沿） |
|---|---|---|
| 0（你的配置） | 0（SCK 空闲低） | 第 1 个边沿（上升沿）采样 |
| 1 | 0 | 第 2 个边沿（下降沿）采样 |
| 2 | 1（空闲高） | 第 1 个边沿（下降沿）采样 |
| 3 | 1 | 第 2 个边沿（上升沿）采样 |

- CPOL 定"SCK 空闲时是 0 还是 1"，CPHA 定"数据在第一个还是第二个边沿被锁存"——**两两组合共 4 种，主从必须一致**，否则读到的是移位半拍的数据（症状：数据错位或全乱）；
- W25Q64 支持模式 0 和模式 3（你的 11-1 软件 SPI 注释"模式 0"、11-2 配的 CPOL_Low+1Edge 也是模式 0）✓；
- **11-1 软件 SPI 的逐 bit 实现**（MySPI.c L54-68）就是模式 0 的教科书手写：先放 MOSI → SCK 拉高（上升沿，从机采样）→ **SCK 高期间读 MISO** → SCK 拉低。注意 L62 读 MISO 在 SCK=1 期间——因为从机也是在上升沿移出数据，主机要在同一拍的高电平窗口读。

## 10.4 硬件 SPI 的寄存器（11-2 配了什么）

| 寄存器 | 你的参数 | 落地 |
|---|---|---|
| CR1.BR[2:0] | Prescaler_128 | 波特率 = 72MHz/128 = **562.5kHz**（W25Q64 上限 104MHz，绰绰有余——这个 128 分频偏保守，调 /4=18MHz 也能跑，面试时可以讲"先求稳后提速"） |
| CR1.CPOL/CPHA | Low + 1Edge | 模式 0 |
| CR1.MSTR | Master | 主机 |
| CR1.SSM/SSI | NSS_Soft | 内部管理 NSS——外部引脚 PA4 手动当片选 |
| CR1.DFF | 8b | 8 位帧 |
| CR2.SSOE | — | 未用 |
| SR | TXE/RXNE | 与 USART 同名同语义（清标志方式也一样：写 DR 清 TXE，读 DR 清 RXNE） |

**NSS 为什么用软件管理？** 硬件 NSS 模式下 SPI 会在每次传输自动拉低/拉高片选，但 W25Q64 的**一条指令 = 多个字节传输**（指令+地址+数据），片选必须**贯穿整条指令**——硬件 NSS 的自动脉冲会把一条指令切成几段。所以 Flash 类器件一律软 NSS，`MySPI_Start/Stop` 手动包住整条指令。这是"软件 NSS 什么时候用"的标准答案。

## 10.5 W25Q64：Nor Flash 的存储模型与三条铁律

- **8MB = 128 块(64KB) = 2048 扇区(4KB) = 16384 页(256B)**——页是最小编程单元，扇区是最小擦除单元；
- **铁律 1：写 = 1→0，擦除 = 0→1**。Flash 单元的物理特性只能单方向改，所以**改写数据必须先擦除**（这就是为什么你的 `W25Q64_PageProgram` 前有 `WriteEnable`、但没有擦除的话写进去是旧数据与新数据的"按位与"）；
- **铁律 2：页内不能跨页**。Page Program 的地址在 256B 页内自增，**超过页尾会绕回页首**（不是进下一页！）。你的 PageProgram 没校验 `count ≤ 256 且不跨页`——4 字节演示没问题，产品级必须处理或拆包；
- **铁律 3：擦写前先 WriteEnable + 写完等 BUSY**。`W25Q64_WriteEnable` 发 0x06 置状态寄存器 WEL 位；`W25Q64_WaitBusy` 轮询状态寄存器 bit0（BUSY/WIP），擦除扇区最长 ~400ms（你的 Timeout=100000 轮询在 562.5kHz 下每拍约 14µs → 上限约 1.4s，够用但要把量级算清）。你的 WaitBusy 有超时，好习惯 ✓。

## 10.6 指令集与你的函数逐条对照（W25Q64 Datasheet）

| 指令 | 编码 | 你的函数 | 注意点 |
|---|---|---|---|
| Write Enable | 0x06 | WriteEnable | 没校验 WEL 是否真的置上（改进点） |
| Read Status Reg-1 | 0x05 | WaitBusy | 循环里持续发 Dummy 读 bit0 |
| JEDEC ID | 0x9F | ReadID | 应读到 **0xEF 0x40 0x17**（Winbond/W25Q64）——你 main 里显示的"ID"就是这个，**上电自检利器** |
| Page Program | 0x02 | PageProgram | 24 位地址**先发高字节**（大端），见下 |
| Sector Erase 4KB | 0x20 | SectorErase | 擦除对象是"地址所在扇区" |
| Read Data | 0x03 | ReadData | 读可以跨页跨扇区连续拉，直到拉高 CS |

**24 位地址的大端发送**（L51-53）：`Address>>16`、`Address>>8`、`Address`——SPI 协议约定地址高位在前（对比 MPU6050 数据也是大端，通信协议几乎清一色 MSB first，这是行业惯例）。地址空间 24 位 = 16MB，W25Q64 用 8MB，高位地址无效部分忽略。

## 10.7 工程体检

1. **11-2 WriteEnable 后没查 WEL**：0x06 之后读状态寄存器 bit1 确认写使能真正生效，能挡住"上一把擦写没完成就发新指令"的时序 bug（BUSY 期间 WEL 会被硬件清掉）；
2. **PageProgram 无跨页保护**（见 10.5 铁律 2）；
3. **11-1 软件 SPI 无延时**：GPIO 翻转全速跑，SCK 频率可能到 MHz 级——W25Q64 受得了，但长杜邦线/面包板上信号质量差；要稳就加延时（对比 10-1 软件 I2C 每个电平 10µs 的思路）；
4. **两种 SPI 的分工**：软件 SPI 换任意引脚、可移植；硬件 SPI 不占 CPU、速率高。11-1→11-2 的演进路线本身就值得在面试里讲。

## 10.8 面试官视角

- "SPI 读一个字节为什么要发 Dummy？"→ 移位环，收发同时。
- "CPOL/CPHA 画四种时序？"→ 白板题；主从不一致的症状。
- "硬件 NSS 和软件 NSS 怎么选？"→ 多字节指令贯穿片选 → 软 NSS。
- "Flash 为什么写前要擦除？页编程跨页会怎样？"→ 1→0 物理约束；绕回页首。
- "W25Q64 的 JEDEC ID 是什么？有什么用？"→ EF 40 17；上电自检/器件识别。
- "SPI 和 I2C 选型？"→ SPI 快、全双工、引脚多（4 线+片选）；I2C 省引脚、带应答、地址寻址。**观点题**，能结合 W25Q64/MPU6050 两个实战说清楚就是满分。

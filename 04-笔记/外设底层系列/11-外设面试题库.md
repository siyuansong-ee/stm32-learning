# 11 · 外设面试题库（面试官视角）

> 与内核篇题库互补：内核篇考"CPU 怎么响应"，本篇考"外设怎么工作"。
> 每题格式：面试官在考什么 → 及格答案 → 加分答案。题号对应 01–10 篇文档。

---

## GPIO / AFIO（对应 01 篇）

**G1. GPIO 的 8 种模式？上拉/下拉由什么决定？** ★★★
- 及格：4 输入（模拟/浮空/上下拉）+ 4 输出（推挽/开漏 × 通用/复用）。
- 加分：CNF=10 时 ODR 决定上/下拉；GPIO_Init 先写 ODR 再写 CRL/CRH 的顺序原因；复用模式下引脚被外设接管、ODR 失效。

**G2. 推挽和开漏的区别？什么时候必须开漏？** ★★★★
- 及格：推挽双向主动驱动；开漏只能拉低。
- 加分：开漏 = 线与，I2C 必须开漏（含时钟拉伸）；"输出 1 = 释放"的物理语义；误用推挽做 I2C 的后果（从机拉低时主机上拉打架）。

**G3. GPIO_Speed_50MHz 是什么？点 LED 选多少？** ★★★
- 加分：压摆率档位不是信号频率；越高 EMI 越大；低速信号选 2MHz；高速通信（SPI 18MHz）才上 50MHz。

**G4. ODR |= 和 BSRR 的区别？** ★★★★
- 及格：BSRR 原子。
- 加分：读改写三步竞态（中断/DMA 改其他位时丢失更新）；"写 0 无效"设计；BRR 只清。

**G5. 按键消抖有哪几种实现？各自的代价？** ★★★
- 加分：延时（阻塞）/状态机轮询（非阻塞）/EXTI+定时器确认/硬件 RC；你的 key.c 是阻塞式，主循环会冻结在 while 等松开。

## EXTI（对应 02 篇）

**G6. EXTI_Init 配了哪几个寄存器？** ★★★★
- 加分：IMR/EMR、RTSR/FTSR、PR 清零；边沿检测是"脉冲检测器"，边沿被锁存到 PR 直到软件清。

**G7. EXTI 和 GPIO 引脚的映射规则？** ★★★★
- 加分：AFIO_EXTICR 同名引脚多选一；PB3 不能进 EXTI7；AFIO 时钟何时需要。

**G8. 为什么 EXTI5-9 共用一个中断向量？ISR 怎么写？** ★★★★
- 加分：7 个通道管 19 条线；GetITStatus 逐线判断 + ClearITPendingBit；GetITStatus vs GetFlagStatus（PR∧IMR vs PR）。

**G9. EXTI 有硬件滤波吗？毛刺干扰怎么办？** ★★★★
- 加分：没有；换 TIM 输入捕获（ICF 数字滤波）；或软件去抖；对射计数乱跳的排查路径。

## TIM 时基（对应 03 篇）

**G10. 定时器溢出瞬间硬件干了什么？** ★★★★★
- 加分：更新事件：UIF 置位、影子寄存器换班、（可选）中断/DMA/TRGO；"事件≠中断"；URS/UDIS 位。

**G11. PSC 为什么写 7200-1？** ★★★
- 加分：寄存器存 PSC+1；ARR/CCR 同款 -1 魔咒；1Hz 推导。

**G12. 运行时改 ARR 为什么不立刻生效？** ★★★★
- 加分：ARPE 预装载 + 影子寄存器；更新事件换班；UG 强制更新或关 ARPE。

**G13. TIM 有哪几种时钟源？** ★★★★
- 加分：内部/ETR/ITR/TIx；你的 6-2 是 ETR 模式 2（SMCR.ECE）；ITR 级联与同步的用途。

**G14. UIF 忘了清会怎样？为什么 Init 里要先 ClearFlag？** ★★★★
- 加分：中断风暴卡死主循环；上电残留标志误触发。

**G15. CKD 和 PSC 什么区别？RCR 是什么？** ★★★★
- 加分：CKD 是 tDTS 滤波器采样时钟；RCR 重复计数器只有 TIM1/8 有，PWM 周期级中断。

## TIM PWM（对应 04 篇）

**G16. PWM 波形的硬件产生过程？** ★★★★★
- 加分：CNT 与 CCR 数字比较 → OCxREF → CCxP 极性 → CCxE → 引脚；零 CPU 参与。

**G17. PWM1/PWM2 区别？占空比公式？边界值？** ★★★★
- 加分：CNT<CCR 有效 vs 反相；CCR/(ARR+1)；CCR=0 恒低、CCR>ARR 恒高。

**G18. PWM 频率和分辨率的权衡？** ★★★★
- 加分：f×分辨率 = CK_CNT；呼吸灯 1kHz/100 级 vs 100Hz/1000 级的取舍。

**G19. 高级定时器 TIM1 和通用 TIM2 做 PWM 差什么？** ★★★★
- 加分：互补输出/死区/刹车/MOE/RCR；TIM1 没波形先查 MOE；H 桥死区防直通。

**G20. 舵机协议为什么 20ms 周期 + 0.5~2.5ms？** ★★★
- 加分：模拟舵机内部闭环采样节奏；1MHz 时基让 CCR=µs；超界要 clamp。

## TIM 捕获 / 编码器（对应 05 篇）

**G21. 输入捕获测频率的完整链路？** ★★★★
- 加分：滤波 IC1F → 边沿选择 CC1P → TI1FP1 → 从模式复位（捕获后清零）→ CCR1 读周期；ARR 只是兜底。

**G22. PWMI 为什么一个引脚能测占空比？** ★★★★★
- 加分：CC2S 选 TI1 + 极性自动取反；CCR1=周期、CCR2=高电平时间。

**G23. 编码器接口模式 vs 两路 EXTI 计数？** ★★★★
- 加分：硬件四沿计数 ×4、方向硬件判断、不丢步；EXTI 方案中断延迟丢步 + 你的 5-2 bug（`EXTI_Line1==SET` 恒假）。

**G24. 测频精度由什么决定？信号断了显示什么？** ★★★
- 加分：计数频率/信号频率；从模式不复位 → CCR1 定格；需要丢失检测。

## ADC（对应 06 篇）

**G25. 12 位 ADC 一次转换多长时间？怎么算？** ★★★★
- 加分：(采样周期+12.5)/ADCCLK；SAR 原理一句话；你的 55.5+12.5=68 拍@12MHz=5.67µs。

**G26. 采样时间由什么决定？** ★★★★
- 加分：源阻抗×采样电容 RC；数据手册阻抗-采样时间表；分压电阻大 → 采样时间拉长。

**G27. 为什么上电要校准？四件套顺序？** ★★★
- 加分：电容阵列失配补偿；ADON→RSTCAL→CAL→触发；稳定期。

**G28. 扫描模式 + 连续 + DMA 怎么配合？** ★★★★
- 加分：SQR 排序列 → CONT 自动重来 → EOC 每通道触发 DMA 请求 → 循环缓冲；你的 8-2 就是答案。

**G29. EOC 怎么清？外设清标志方式有哪些？** ★★★★
- 加分：ADC 读 DR 清、USART 读 DR 清、TIM 写 0 清、EXTI 写 1 清、DMA 写 1 清——全家桶各不同，考手册功底。

## DMA（对应 07 篇）

**G30. DMA 搬运时 CPU 在干嘛？DMA 真的免费吗？** ★★★★
- 加分：总线矩阵仲裁；带宽竞争插入等待；不占 CPU 但占总线。

**G31. 为什么 ADC1 必须 DMA1_CH1？** ★★★★
- 加分：请求线固定映射表；配错通道永远不触发；M2M 不占请求线。

**G32. 重配 CNDTR 为什么要先关 EN？** ★★★
- 加分：运行中改未定义；普通模式跑完 CNDTR=0 必须重装。

**G33. 循环模式 + 半传输中断能做什么？** ★★★★
- 加分：乒乓缓冲零拷贝；单缓冲的数据撕裂与 volatile。

## USART（对应 08 篇）

**G34. TXE 和 TC 的区别？** ★★★★
- 加分：TDR 空 vs 发送机空闲；连续发等 TXE、确认发完等 TC（RS485 切方向）。

**G35. 72MHz、115200 的 BRR 怎么算？误差多少？** ★★★★★
- 加分：468.75 那套：USARTDIV=fCK/(16×Baud)，整数 4 位小数；误差>3% 通信失败。

**G36. ORE 溢出是什么？怎么清？** ★★★★
- 加分：RDR 没读新帧到达 → 丢字节；先读 SR 再读 DR；高速连续收随机丢数据的排查。

**G37. printf 在 Keil 上卡死是什么原因？** ★★★★
- 加分：半主机 semihosting（BKPT 0xAB）；MicroLIB 或重写 fputc/_sys；你的重定向是强符号覆盖弱符号。

**G38. 你的 HEX/文本数据包状态机好在哪？还缺什么？** ★★★★
- 加分：ISR 最小化、截断防越界、丢包重同步；缺 ORE 处理与校验和。

## I2C / MPU6050（对应 09 篇）

**G39. 画出 I2C 写一个寄存器的完整波形。** ★★★★★
- 加分：START/从机地址/ACK/寄存器/ACK/数据/ACK/STOP；SCL 高期间 SDA 稳定的约束与 START 定义的呼应。

**G40. 为什么要重复起始？ACK 是谁发出的？** ★★★★
- 加分：换方向不释放总线防被打断；接收方拉低；读寄存器序列。

**G41. F1 硬件 I2C 的 BUSY 卡死怎么回事？** ★★★★
- 加分：从机异常复位总线中间态；SWRST+GPIO 翻 9 时钟恢复；超时保护（你的 WaitEvent 方向对）。

**G42. 硬件 I2C 和软件 I2C 怎么选？** ★★★★
- 加分：观点题——小数据量通用性 vs 大数据量 CPU 占用；F1 勘误成本；连续读 14 字节的一致性优势。

## SPI / W25Q64（对应 10 篇）

**G43. SPI 读数据为什么要发 Dummy 字节？** ★★★★
- 加分：移位环、收发同时；CPOL/CPHA 四种模式画出。

**G44. Flash 为什么写前要擦除？页编程跨页会怎样？** ★★★★
- 加分：1→0 物理约束；跨页绕回页首；页 256B/扇区 4KB/块 64KB。

**G45. 硬件 NSS 为什么不适合 W25Q64？** ★★★
- 加分：指令多字节贯穿片选；软 NSS；SPI 无应答机制（对比 I2C），状态全靠状态寄存器轮询（BUSY）。

**G46. SPI 和 I2C 的选型对比？** ★★★★
- 加分：速率/引脚数/寻址/应答/时钟拉伸；结合 W25Q64 与 MPU6050 实例。

## 面试前速览清单（外设篇）

1. 清标志全家桶：TIM 写 0 / EXTI 写 1 / ADC·USART 读 DR / DMA 写 1。
2. -1 魔咒：PSC/ARR/CCR 全部存 N+1。
3. PWM 信号链：CNT vs CCR → OCxREF → 极性 → 使能 → 引脚；频率×分辨率=CK_CNT。
4. 捕获链：滤波 → 边沿 → 从模式复位；PWMI 的 CCR1=周期 CCR2=高电平。
5. ADC：采样+12.5 拍；阻抗×电容定采样时间；上电校准四件套。
6. DMA：通道映射表、CNDTR 停写、循环+半传输乒乓。
7. USART：BRR 公式、TXE/TC、ORE 先 SR 后 DR。
8. I2C：开漏线与、START 定义、EV5/6/8、BUSY 卡死三板斧。
9. SPI：移位环、四模式、软 NSS、Flash 三铁律。

---

## 一、定时器的本质：一个会数数的计数器

定时器内部就是三个东西在循环工作：

```
时钟(72MHz) ──PSC 预分频──> 计数脉冲 ──CNT 每个脉冲+1──> 数到 ARR 就溢出(归零重来)
```

- **PSC（预分频器）**：把 72MHz 降速，实际分频系数 = PSC+1
- **ARR（自动重装载）**：计数上限，CNT 数到 ARR 就溢出，同时产生"更新事件"（可触发中断）
- **CNT（计数器）**：当前计数值

**万能公式（必背）**：

> **溢出时间 T = (ARR+1) × (PSC+1) / 72MHz**

例：PSC=7199、ARR=9999 → T = 7200 × 10000 / 72M = **1 秒**

定时器的四种"职业"（就是你 6-1~6-8 学的全部）：
1. **定时器**——溢出触发中断（6-1）
2. **计数器**——数外部引脚的脉冲（6-2）
3. **PWM 发生器**——输出比较，产生方波（6-3/4/5）
4. **测量仪**——输入捕获测频率占空比、编码器测速（6-6/7/8）

## 三、四条标准配置流程（核心，背到能默写）

### 流程 1：定时中断（6-1）

```c
/* ① 开时钟：TIM2 挂在 APB1（TIM1/8 才在 APB2） */
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

/* ② 时基初始化：ARR 和 PSC 按公式算好 */
TIM_TimeBaseInitTypeDef tb;
tb.TIM_Period = 9999;                    // ARR
tb.TIM_Prescaler = 7199;                 // PSC → 1 秒溢出
tb.TIM_CounterMode = TIM_CounterMode_Up; // 向上计数
tb.TIM_ClockDivision = TIM_CKD_DIV1;
TIM_TimeBaseInit(TIM2, &tb);

/* ③ 允许更新中断 + NVIC 开通道 */
TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);
NVIC_InitStructure.NVIC_IRQChannel = TIM2_IRQn;   // 通道号查启动文件
NVIC_Init(&NVIC_InitStructure);

/* ④ 启动 */
TIM_Cmd(TIM2, ENABLE);

/* 中断服务函数（名字必须和启动文件一致） */
void TIM2_IRQHandler(void) {
    if (TIM_GetITStatus(TIM2, TIM_IT_Update) != RESET) {
        /* 每秒要做的事 */
        TIM_ClearITPendingBit(TIM2, TIM_IT_Update);  // ★必清标志
    }
}
```

### 流程 2：PWM 输出（6-3 呼吸灯 / 6-4 舵机 / 6-5 电机，同一套配方）

```c
/* ① 开时钟：GPIO + AFIO + TIM（三个都要！） */
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA | RCC_APB2Periph_AFIO, ENABLE);
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);

/* ② GPIO 配成复用推挽（把引脚交给 TIM）★最常漏 */
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF_PP;
GPIO_Init(GPIOA, &GPIO_InitStructure);

/* ③ 时基：ARR 决定 PWM 频率 f = 72MHz / ((PSC+1)×(ARR+1)) */
/* ④ 输出比较通道：CCR 决定占空比 */
TIM_OCInitTypeDef oc;
oc.TIM_OCMode = TIM_OCMode_PWM1;           // CNT<CCR 输出有效电平
oc.TIM_OutputState = TIM_OutputState_Enable;
oc.TIM_Pulse = 50;                         // CCR 初值
oc.TIM_OCPolarity = TIM_OCPolarity_High;
TIM_OC1Init(TIM2, &oc);

/* ⑤ 启动；运行中改占空比用 TIM_SetCompare1 */
TIM_Cmd(TIM2, ENABLE);
```

**三个应用的关键参数（记这张表就够）**：

| 应用 | PSC | ARR | 频率/周期 | CCR 与效果 |
|---|---|---|---|---|
| 呼吸灯 | 71 | 99 | 1kHz | CCR 0→100 渐增渐减 = 亮度呼吸 |
| 舵机 | 71 | 19999 | 50Hz / 20ms | CCR=500→0°，1500→90°，2500→180°（脉宽 0.5/1.5/2.5ms） |
| 直流电机 | 71 | 99 | 1kHz | CCR 0–100 = 转速 0–100%，越大越快 |

> 舵机换算口诀：**CCR 值 = 脉宽(ms) × 1000**（因为 PSC=71 时 1 个计数 = 1µs）。

### 流程 3：输入捕获测频率（6-6）与 PWMI（6-7）

**原理**：引脚来一个边沿，硬件瞬间把当时的 CNT 值锁存进 CCR 并触发中断；两次捕获的 CNT 差值 = 两个边沿之间的计数个数，除以计数频率就是时间。

```c
/* ① 开时钟：GPIO + TIM */
/* ② GPIO 配浮空输入（信号进来） */
/* ③ 时基：PSC=71 → 计数频率 1MHz（1 个计数 = 1µs） */

/* ④a 测频率（6-6，用两个通道交叉捕获同一引脚，兼顾低频） */
TIM_ICInitTypeDef ic;
ic.TIM_Channel = TIM_Channel_1;
ic.TIM_ICPolarity = TIM_ICPolarity_Rising;    // 上升沿捕获
ic.TIM_ICSelection = TIM_ICSelection_DirectTI;
ic.TIM_ICPrescaler = TIM_ICPSC_DIV1;
ic.TIM_ICFilter = 0x0F;
TIM_ICInit(TIM2, &ic);
/* 频率 f = 1MHz / (两次捕获 CCR1 的差值) */

/* ④b PWMI（6-7，一个引脚测频率+占空比，双通道各捕获一个边沿） */
/*    TI1FP1 → 上升沿 → CCR1 存周期；TI1FP2 → 下降沿 → CCR2 存高电平时间 */
/* 频率   = 1MHz / (CCR1 + 1) */
/* 占空比 = (CCR2 + 1) / (CCR1 + 1) */

/* ⑤ 捕获中断 + NVIC + 使能；中断里读完 CCR 记得清标志 */
```

### 流程 4：编码器测速（6-8）

```c
/* ① 开时钟：GPIOA + AFIO + TIM3 */
/* ② GPIO：A/B 两相都配上拉输入 */
/* ③ 时基：ARR = 65535（16 位拉满） */
/* ④ 编码器接口模式：TI1+TI2 同时输入，上升沿计数 */
TIM_EncoderInterfaceConfig(TIM3, TIM_EncoderMode_TI12,
                           TIM_ICPolarity_Rising, TIM_ICPolarity_Rising);
/* ⑤ 使能 */
TIM_Cmd(TIM3, ENABLE);

/* 测速：固定时间间隔（如 10ms）读一次 CNT
   转速 = (本次CNT − 上次CNT) / 时间 / 每圈脉冲数
   每圈脉冲数 = 编码器线数 × 4（正交四倍频）
   CNT 差值正负 = 正转/反转（硬件自动判方向）*/
```

## 四、公式速查表

| 求什么 | 公式 |
|---|---|
| 溢出/定时时间 | T = (ARR+1)(PSC+1) / 72MHz |
| PWM 频率 | f = 72MHz / ((PSC+1)(ARR+1)) |
| PWM 占空比 | CCR / (ARR+1)（模式 1） |
| 舵机 CCR | CCR = 脉宽(ms) × 1000（PSC=71 时） |
| 捕获测频 | f = 1MHz / (两次 CCR 差值)（PSC=71 时） |
| PWMI 频率 | f = 1MHz / (CCR1+1) |
| PWMI 占空比 | (CCR2+1) / (CCR1+1) |
| 编码器转速 | (ΔCNT / 时间) / (线数×4) × 60 rpm |

## 五、常见坑（8 条，条条都是真实翻车点）

1. **忘开 AFIO 时钟**（用 PWM 复用、编码器、外部时钟都涉及）
2. **PWM 引脚忘配复用推挽**——配成普通推挽，PWM 永远出不来
3. **算错定时器时钟**——TIM2-7 虽挂 APB1(36MHz)，但定时器时钟是 72MHz
4. **忘 TIM_Cmd 使能**——配了半天定时器根本没转
5. **中断里忘清标志**——程序卡死在中断里
6. **输入捕获只配一个通道**——测低频要交叉捕获（6-6 的坑）
7. **舵机用错频率**——舵机必须 50Hz，PWM 频率错舵机狂抖
8. **编码器忘了上拉输入**——悬空输入读不到干净的 A/B 相

## 六、与微机原理的串联（一句话）

**TIM ≈ 8253 的现代版**：8253 计数初值 = 时钟÷目标频率，TIM 的 (PSC+1)(ARR+1) 就是把这个除法拆成两级（因为 16 位装不下大分频比）。8253 方式 3 方波 = PWM 雏形；8253 方式 0 计数结束中断 = 更新中断思想。
